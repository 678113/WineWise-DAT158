Dataset: UCI Wine Quality (Cortez et al., 2009), https://archive.ics.uci.edu/dataset/186/wine+quality

Run `python -m src.data --download` to obtain winequality-red.csv and winequality-white.csv from the UCI repository. If downloading fails, manually download those files from the UCI Wine Quality dataset page and place them in this directory. The default project trains on red wine only.
